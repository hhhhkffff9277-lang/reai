# Example Output Shape

This example captures the expected texture of a WeChat article package without requiring API generation.

## Title

养老机器人先戳中了子女的愧疚

## Digest

当大多数人仍在讨论养老床位缺口时，一个更隐蔽的变化已经发生：机器人真正替代的不是护工，而是子女心里那句说不出口的亏欠。

## Opening Pattern

Start with a concrete, almost cinematic scene:

- A specific room or facility.
- One person or one machine.
- A surprising reduction in guilt, fear, cost, risk, or friction.
- A judgment that reframes the visible event through technical, commercial, social, psychological, and institutional mechanisms.

The first body sentence should not repeat the title.

## Stance Wizard Pattern

```markdown
## 立意wizard
- 钩子：子女愿意为一种更体面的愧疚付费。
- 立场：这不是养老机器人的技术进步故事，而是家庭照护责任的重新分配。
- 案例：护理机构成本、家庭照护时间、具体设备或服务流程。
- 演示方向：从一台机器进入浴室开始，拆出谁少承担了风险，谁获得了新的收费理由。
- 风险评估：不夸大替代护工，不暗示某公司投资价值，不把家庭选择写成道德审判。
```

## Section Pattern

Use a mix of:

- Scene-based section.
- Data/conflict section.
- Company or product logic section.
- Core judgment section.

After each major section, add an image suggestion:

```text
【插图建议】
类型：实景示意图
内容描述：一个充满现代感的无障碍浴室，顶部装有天花板轨道，浴缸一侧嵌入触摸屏，整体色调温暖、洁净，没有护理人员出镜。
是否需要生成：是
```

When a comparison or matrix is needed, add an image-based table placement instead of a Markdown pipe table:

```text
【图片式表格】
位置：机制拆解后
文件名：images/table-01.png
内容：三列对比“谁获得便利 / 谁承担成本 / 谁失去选择权”，每格不超过 18 个字。
是否需要生成：是
```

## Strong Closing Pattern

End with a concrete takeaway:

```text
带走一句话：养老机器人卖的不是技术，是子女终于可以睡着的那一晚。
```

The exact sentence will vary by topic, but it should be crisp, specific, and slightly counterintuitive.

End with a question:

```text
如果有一天机器照顾得比家人更稳定，你会觉得这是解脱，还是另一种亏欠？
```
